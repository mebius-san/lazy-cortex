# lazycortex-diagram — pending changes

## Highlights since `1.1.5`

- Node labels in flowchart-shaped mermaid diagrams are now always quoted. Mermaid reads the character after the opening bracket as a shape modifier, so a label starting with a slash — natural when a node is named after a slash-command — produced an unterminated parallelogram that failed to render. A pre-write check rejects any unquoted label and the shipped exemplars were requoted to match.
