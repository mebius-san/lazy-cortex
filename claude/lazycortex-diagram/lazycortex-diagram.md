# lazycortex-diagram — changed since publish

**Status**: changed — version `1.1.7` is ahead of the published `1.1.6`; commits have landed under `claude/lazycortex-diagram/` since the last release.

## Highlights since 1.1.6

- `/lazy-diagram.install` no longer walks you through a prompt per rule file. Rule mirrors are byte-compared against the shipped source and anything stale is overwritten in place, with each write verified before it is reported; a rule the plugin has retired is still left alone.
- Block-based diagrams (`layout`, `screen-scheme`, `controls-scheme`) no longer come out with unreadable pale blocks or arrows the renderer cannot place. Every region a diagram declares now gets its colour, a layout stays a flat grid of regions, and a request that really wants arrows is sent back to be drawn as a flow or an architecture instead.
- Diagrams read correctly again on current Obsidian, in both light and dark mode. Newer Mermaid quietly stopped honouring the colouring routes several diagram kinds relied on, which left block diagrams pale, entity-relationship rows flat, and user-journey bands mis-coloured; each of those five kinds now uses a route the current renderer actually applies, so the palette survives the theme switch instead of turning into white-on-white.
