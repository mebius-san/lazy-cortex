# lazycortex-core — minor bump pending

**Status**: changed — working version `5.19.0` is ahead of the published `5.18.1`. Re-running the install skill is required once this ships, so the new `git` settings keys land in each consumer.

## Highlights since 5.18.1

- The git guard gained a second, default-on behaviour: commits must name their paths, so an agent can no longer sweep operator-parked content out of the shared index. `git add` is limited to intent-to-add, `git rm` / `git mv` are refused, and the staging-window mutex stays available behind a flag for repos that prefer it.
- The daemon now rides out a brief network blip instead of halting on it — remote fetches and pushes retry with backoff, while anything the remote itself refused still surfaces on the first attempt.
