# lazycortex-core — changed since publish

**Status**: changed — version `5.18.1` is ahead of the published `5.18.0`; the changes below are waiting for the next publish.

## Highlights since 5.18.0

- The daemon gate `daemon.run_here` now accepts a list of hostnames, so a checkout living on a file-synced path (Dropbox, iCloud, Syncthing) names the one machine allowed to run its daemon instead of leaking a `true` to every machine holding that path. Installing on a host outside the list also removes the supervisor unit that machine already has, so a stray daemon cleans itself up on the next install run.
