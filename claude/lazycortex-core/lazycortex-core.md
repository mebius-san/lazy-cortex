# lazycortex-core — changed since publish

**Status**: changed — version `5.20.3` is ahead of the published `5.20.2`; the changes below are waiting for the next publish.

## Highlights since 5.20.2

- The background daemon no longer fills the disk with logs nobody reads. Its metrics endpoint was writing one line per scrape into the error log the supervisor keeps forever — several thousand lines a day per project — and the daily journal recorded every routine tick that found nothing to do, which was almost all of them. Both are gone; real errors, slow ticks, and ticks that actually dispatched work still appear. The hourly cleanup now also covers dated journals written by other plugins, which previously grew without limit, and trims the supervisor's own capture files once they pass a megabyte while keeping the most recent output.
