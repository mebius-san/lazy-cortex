# lazycortex-core — changed since publish

**Status**: changed — version `5.20.2` is ahead of the published `5.20.0`; the changes below are waiting for the next publish.

## Highlights since 5.20.0

- Install now works out how the daemon talks to `origin` instead of leaving that block empty: it takes the branch the checkout is on and turns on push-back when the checkout has a remote. Previously a daemon-enabled repo could commit its routines' work into a runtime checkout and never publish it, with no question and no default to get out of that state; audit reports the gap on existing installs and doctor offers to fill it in. A block written by hand is left exactly as it is.
- Restoring working directories that live outside git no longer leaves the repository looking dirty. After the directories are linked back in, install checks whether git can still see them and offers to add the exact lines that hide them, quoting each one first — the usual `Data/` entry covers a folder, not the link that stands in for it, so a project that looked correctly configured would still stall the background daemon on its first tick. Existing entries are never rewritten, the report says which of the two reasons applies, and declining leaves a warning rather than a silent dirty tree.
