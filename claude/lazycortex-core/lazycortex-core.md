# lazycortex-core — changed since publish

**Status**: changed — version `9.0.0` is ahead of published `8.1.0`; unpublished work has landed under `claude/lazycortex-core/`.

## Highlights since 8.1.0

- The audit and doctor no longer judge every skill, agent, and command description against the trigger shapes on each pass — they only verify the `description:` field exists. Trigger-shape quality is now purely an authoring-time concern, which removes the most expensive judgement pass from the weekly autocheckup runs.
- Network-shaped git halts now heal themselves: the hourly doctor tick's remote probe clears not only an unreachable-remote halt but also a `git_local_failed` halt raised by a git sync step — the class a transient network failure lands in when its stderr misses the transport markers.
- The settings-migration ladder for the review section gained a step that attaches the specs plugin's new doc-height protocol to every `design` / `system-design` class on consumer vaults, so already-installed repos pick the height contract up on their next update pass.
- Breaking rename: `lazy-core.optimize` is now `lazy-core.slim-context` — the old skill name is gone with no alias.
- A second review-migration step (v10 → v11) seeds the specs plugin's new `vision` / `system-vision` review classes into consumer vaults and lets the `use-cases` class cover a content-root `use-cases.md`.
- The audit gained a review-class self-validation check: a class whose validator shares its main writer's expert key is now a FAIL finding, and agent discovery filters the machine-global plugin cache by install scope so a project-scoped plugin no longer surfaces in every repo's run.

- Daemons can be paused per repo: a local `.runtime/daemon.pause` semaphore, `daemon-pause` / `daemon-resume` CLI verbs, and a paused gauge the Daemons dashboard surfaces as a PAUSED state.
- The markdown-style canon pins decision callouts to the prose that owns them, defines the reference forms a promote leaves behind, and makes weaving leftover reference lines into their owners part of the writer's ordinary round.
