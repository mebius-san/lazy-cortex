# lazycortex-obsidian — changed since publish

**Status**: changed — version `4.0.0` is ahead of the published `3.1.0`; the pending cycle below ships with the next publish.

## Highlights since 3.1.0

- Vault discovery no longer needs a deployed `.obsidian/` directory: the iconize worker resolves the vault root as the git toplevel of the current checkout (an explicit `--vault` override just has to name an existing directory). Headless checkouts — runtime clones, CI — repaint again after the vault-manifest migration made `.obsidian/` untracked; a checkout outside any git repository gets a clear `vault not found` error instead of a walk-up miss.
- The plugin no longer carries Obsidian themes or a copy of a vault's top-level config files. A theme's CSS was never something the manifest recorded, so `/lazy-obsidian.deploy` now names a theme the vault is missing and leaves installing it to Obsidian's own Appearance settings, instead of restoring one of three vendored stylesheets. Personal vault assets belong in your dotfiles; the manifest keeps carrying the theme's name.
