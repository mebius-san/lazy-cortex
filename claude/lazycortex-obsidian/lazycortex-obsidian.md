# lazycortex-obsidian — changed since publish

**Status**: changed — version `5.1.0` is ahead of published `5.0.3`; unpublished commits sit under `claude/lazycortex-obsidian/`.

## Highlights since 5.0.3

- Plugin-shipped icon registries are discovered from the plugin cache on a consumer vault (newest version of every installed plugin), so plugin icons paint outside a dev vault; registry layers are named by the plugin manifest rather than the version directory.
- Every question `lazy-obsidian.*` skills raise now prints a context block first (which step, what was found, why it asks, what each answer does now and later) and names its target; `lazy-obsidian.audit` drops the `waive` option that never persisted anything, leaving `fix` / `skip`.
- The icon-map gains `paint_roots`, a list of vault directories the worker may paint inside; outside them a note is passed over entirely (never painted, never stripped). `/lazy-obsidian.iconize-install` seeds it with the spec catalog root from `spec.vault_root` (default `specs`) and never rewrites an authored value; a map without the key keeps painting the whole vault.
- A matcher may resolve a colour without an icon: an `{{frontmatter.iconize_icon}}` template that comes back empty now yields a colour-only entry and the note keeps its own icon, so state registries can recolour a note without ever replacing its type icon.
