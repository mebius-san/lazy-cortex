# lazycortex-python — changed since publish

**Status**: changed — version `3.0.0` is ahead of the published `2.4.2`; commits have landed under `claude/lazycortex-python/` since the last release.

## Highlights since 2.4.2

- `/lazy-python.install` mirrors rules by comparison rather than judgement: the shipped set is enumerated from the plugin at run time (a newly added rule can no longer be missed), a target whose bytes differ is replaced wholesale instead of hand-merged, every write is re-read to confirm it landed, and the phase prints a receipt naming each rule's outcome.
- The docstring checker no longer mistakes a documented name for a development marker: a parameter or attribute called `limit`, `opt`, or `guard` is read as the entry it is when it opens a line under `Args:`, `Attributes:`, `Raises:`, or `Type Parameters:`, while the same token in narrative text is still reported.
- Fixing a bug now starts with a test that fails on the unchanged code, for the cause the report names: the testing canon gained a *Fixing a Bug* policy covering that order, where the regression test lands (one more method in the existing test file for the source that carried the defect, never a `test_bug_<id>.py`), and the narrow exception for defects no unit test can reach. Both LLM-read rules carry the reminder, so it fires whether you open the production file or the test.
- Design decisions now live next to the code, and a marker's register tells you what it is. The new `Decision:` marker records a chosen-over-rejected fork with its why (empty thesis is a checker finding; in docstrings only a line-start token counts, so domain prose stays untouched), a contract marker must carry guarantee text on the lines below it, and the register scheme renames `DOC(…)` to `Domain(…)`, `Contract!` to `Contract:`, `REF:` to `ref:` — CAPS for temporary marks, Capitalized for standalone knowledge blocks (now fenced by blank lines the checker enforces), lowercase for one-line annotations. Existing consumer code migrates with a one-shot rename pass.
