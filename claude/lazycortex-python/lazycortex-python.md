# lazycortex-python — changed since publish

**Status**: changed — version `2.3.0` is ahead of the published `2.2.0`.

## Highlights since 2.2.0

- The style rule no longer bans module-level functions. It now recommends a class when the functions share state, a namespace or a lifecycle, and accepts a flat module of functions for a standalone script or worker that has none of those — which is what the rule's own consumers were already writing. Alongside it, a module docstring became legal in a file that defines no classes: a class documents itself, so a docstring above one duplicates or contradicts that contract, but a flat CLI entry point has nowhere else to say what the file is for. Re-run `/lazy-python.install` to refresh the mirrored rule and the scaffold template.
- `pcf`'s copyright-spacing check stopped misfiring on files that open with a module docstring. It read a shebang as the start of a copyright block and demanded a blank line immediately after it, which no file carrying a docstring between the two can satisfy; the check now measures the spacing below the docstring.
- `/lazy-python.audit`'s rule-pointer check no longer uses `Path.glob`, which the tech rule bans across plugin sources for its version-dependent `**` semantics.
- `pcf` now enforces the half of the purpose-comment rule a parser can actually prove: every block inside a function body must open with a comment, and a `# waiver:` / `# noqa` / `# type:` / `# pylint:` / `# fmt:` / `# noinspection` line does not count as one. Clause headers (`except`, `else`, `elif`, `finally`, `case`), the continuation of a call split across a blank line, the docstring, a nested function's header, and the body's opening block are all left alone. The check is on by default — a repo that has never done this cleanup will light up on the first run and can stage the work with `[tool.pcf] check_block_comments = false`. Judging whether the comment says anything stays with the review phase, and the code-reviewer agent now looks for hollow comments rather than missing ones.
