# lazycortex-python — changed since publish

**Status**: changed — version `4.1.0` is ahead of the published `4.0.1`; the pending cycle below ships with the next publish.

## Highlights since 4.0.1

- The seeded checker policy now admits Greek letters in comments and docstrings out of the box: the `pyproject.toml` template ships `allowed_languages = ["english", "greek"]` under `[tool.pcf]`, so domain formulas can spell `π` and friends without a per-project override. Existing consumer configs keep their own `[tool.pcf]` section — the key reaches them via the cross-project migration, not the template merge.

- The knowledge sweep now runs end to end without stopping to ask: it settles the group cut itself, reconciles unknown groups, and closes with a consolidation pass that judges every group name against the whole corpus rather than one dispatch at a time — collapsing synonyms, splitting overloaded groups, and refiling the blocks whose group moved. The report still hands the operator every name and boundary to overrule, now against a finished dictionary. Alongside it, the domain writer enumerates a file end to end before writing anything instead of stopping at the first mechanic it notices, and both writers judge a candidate against the code alone — a nearby comment, docstring, or another marker block is no longer grounds to skip one.

- The sweep's contract half gained its own closing consolidation pass: the blocks the writers produced are judged as one corpus — canon-excluded formalism is cut, sibling classes converge on one phrasing, and duplicate guarantees fold into a single block, but only when both copies speak to the same readers (a hook that subclasses override keeps its copy even when the text matches word for word). Presentation details — exact message text, log lines, output formatting — are now excluded from contract eligibility across the documenting canon and the contract-writer.
