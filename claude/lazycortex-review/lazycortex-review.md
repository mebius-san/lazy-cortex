# lazycortex-review — changed since publish

**Status**: changed — version `6.2.0` is ahead of the published `6.1.0`; the pending cycle below ships with the next publish.

## Highlights since 6.1.0

- Finalize is now gated on the `# History` line: a cycle that reached an approved state must have its line written before the closing transition, and an empty `# History` on a finalized document — report journals included — is named a coordinator failure.
- The coordinator routine trio is registered on every checkout — install no longer unregisters `lazy-review.collect`, `lazy-review.coordinator-watch`, and `lazy-review.sanitize` on a repo that runs no background daemon, since `/lazy-runtime.tick` fires them by hand.
- Review skills state their execution order through a written-out step ledger instead of the Task checklist tool, with the canonical step list and per-step outcome words unchanged.
- The coordinator watch no longer loses wakes shadowed by a later bot commit in the same window: a review entry fires from the document's own state when the transition was buried, and a `last_seen_sha` cursor in the runtime sidecar lets the watch rescue an operator commit a bot commit landed on top of.
- Every review commit verb — the coordinator's wake commit, the round and finalize landings, start/stop/submit — now commits under an explicit pathspec, and an empty round marker pins its tree to HEAD, so content someone else staged into the shared index is never swept into a review commit.
