# lazycortex-wiki — changed since publish

**Status**: changed — version `2.1.0` is ahead of the published `2.0.0`; the pending cycle below ships with the next publish.

## Highlights since 2.0.0

- Wiki routines are registered on every checkout: `/lazy-wiki.install` and `/lazy-wiki.configure` no longer skip routine registration on a repo without a background daemon, since `/lazy-runtime.tick` fires the same scans by hand.
- Wiki skills state their execution order through a written-out step ledger instead of the Task checklist tool; `/lazy-wiki.configure` resolves its branch first and writes only that branch's ledger.
- Tags move onto an axis-based canon: a new `lazy-wiki.tag-curator` expert normalizes a scope's `wiki.tags.dictionary` axis values (dispatched via tag-tick / `normalize-tags`), the domains surface of `TagOps` lets the same collect/retag pipeline run over generated domain docs, and `/lazy-wiki.doctor` flags a domain doc carrying an axis the dictionary doesn't declare. The old per-block `[tag]` bracket syntax is gone from the domain-groups template and the Domain comment canon.
